# مولد دفتر الغياب

تطبيق سطح مكتبي باستخدام PyQt6 لإنشاء دفاتر غياب للطلاب من ملفات Excel.

## الميزات
- تقارير يومية وشهرية
- دعم العطل الرسمية في الأردن
- واجهة عربية وداعمة لاتجاه اليمين إلى اليسار
- إنشاء ملفات Excel جاهزة للطباعة

## التثبيت
1. افتح المجلد في سطر الأوامر.
2. أنشئ بيئة افتراضية:
   ```bash
   python -m venv .venv
   ```
3. شغّل البيئة:
   ```bash
   .\.venv\Scripts\activate
   ```
4. ثبّت المتطلبات:
   ```bash
   pip install -r requirements.txt
   ```
5. شغّل التطبيق:
   ```bash
   python main.py
   ```

## البناء إلى ملف قابل للتنفيذ
```bash
python build.py
```
